# 02 · 指标与「上下文驱逐」隔离协议（T0 交付物 3/3 · 核心）

> 日期：2026-09-29（跑 `Get-Date` 读得）。
> **本文档是 T0 的验收物**：其中每一条协议都必须能写成**可执行断言**，否则不算 T0 完成。

---

## 1. 为什么需要"隔离协议"

本项目要证明的是：**模型的答案来自参数里的记忆，而不是来自上下文**。

如果记忆内容还在上下文里，模型完全可以"偷看"，此时 100% 的准确率**不能**归因给参数记忆。
更进一步，即使把原文删掉，模型仍可能从**残留线索**（标题、实体名、格式、"刚才提到的那个"）
猜出答案。所以"删掉原文"是不够的，必须有一套**可执行**的隔离与对照协议。

> 一句话判据：**同一个上下文、同一个提示词，唯一变化是"旁路记忆开/关"，答案应当随之变化。**

## 2. 隔离协议 P1–P5

### P1 · 驱逐检查（Eviction Check）——必做，自动
读取时对上下文做**三重匹配**，任一命中即判定该样本**不可归因**并丢弃：
1. 记忆值的**精确子串**（原文匹配）；
2. **规范化匹配**（去空白/标点/大小写/全半角后匹配）；
3. **数值/日期归一匹配**（"3 月 3 日" ≡ "March 3" ≡ "03-03"）。

实现位置：`bench/protocol.py::assert_evicted(context_text, memory_value) -> EvictionReport`。
**判据**：驱逐检查失败的样本不许进入主指标，只在附录报告其数量。

### P2 · 反事实写入（Counterfactual Write）——必做
每次写入的值**按种子随机生成**（虚构实体 + 随机值），同一问答对在不同种子的运行里写入**不同值**。
- 若模型答出**本次写入的值** ⇒ 只可能来自写入；
- 若模型答出**另一个种子的值** ⇒ 说明有跨运行污染（缓存/持久化串了），**立即报警**。

**判据**：跨种子答案分布应当集中在"本次写入值"上；否则实验结果无效。

### P3 · 负对照 / 置换对照（Negative Control）——必做
写入事实 $A$（如"Velmora 的首都是 Trennick"），然后对**从未写入**的查询（如"Garlund 的首都是？"，
该实体在本次会话从未出现）提问：
- 若不写入任何内容时正确率 ≈ 0，而写入后该未写实体的正确率**没有上升** ⇒ 说明增益是"特定记忆"而非"格式/幻觉倾向"；
- 若未写实体的正确率**也上升** ⇒ 说明模型在**编造**，主指标不可信。

**判据**：`增益(已写) >> 增益(未写) ≈ 0`；否则视为"格式效应"，须重做提示词设计。

### P4 · 适配器消融（Adapter Ablation）——**最强因果证据**，必做
读取时，**保持上下文与提示词逐字节相同**，只切换：
| 条件 | 旁路 | 期望 |
| --- | --- | --- |
| `MEM_ON` | 已写入的槽 active | 高正确率 |
| `MEM_OFF` | 所有槽擦除/置零 | **回落到基线** |
| `MEM_SHUFFLE` | 只开**其它**槽（不含目标记忆） | 接近基线 |

**判据**：`MEM_ON > MEM_OFF ≈ MEM_SHUFFLE`，且差值有置信区间（bootstrap，报告 95% CI）。
若 `MEM_OFF` 仍然很高 ⇒ 一定有泄漏，实验作废。

### P5 · 提示词对照（Prompt-Only Control）——必做
同样的"查询 → 答案"提示词模板，但**旁路从头到尾未写入**。
用于剥离"提示词格式本身带来的收益"。

**判据**：`MEM_ON − PromptOnly` 才是记忆的净贡献，主表报告这个差值（Δ 列）。

## 3. 指标定义

### 3.1 主指标：驱逐后记忆命中（RQ1）

| 指标 | 定义 |
| --- | --- |
| **EM** | 记忆值精确匹配率（规范化后） |
| **F1** | token 级 F1（部分正确也算） |
| **ΔEM** | $EM(\text{MEM\_ON}) - EM(\text{PromptOnly})$ —— **主报告量** |
| **写入成功率** | 写完后在 **P4 条件下**能否召回（区分"没写进"与"写进了读不出"） |

### 3.2 遗忘质量（RQ2）

- **保留率@重要**（`retention_important`）：容量满后，重要项（被访问过/被显式标记）仍能召回的比例；
- **保留率@噪声**（`retention_noise`）：噪声项仍占槽的比例（**越低越好**）；
- **判别力** = `retention_important − retention_noise`（越大越"只忘该忘的"）；
- **基座能力探针**（`capability_drift`）：固定通用样本集（bits）上的性能漂移；
  **预算**：T2 先设"漂移 ≤ 2%"为通过线（可调），且必须在论文里报告绝对数值而不只是"影响很小"。

### 3.3 上下文惯性（RQ3）

三臂对照：`A_无记忆` / `B_上下文记忆`（把同样内容放进上下文） / `C_参数记忆`。

| 指标 | 定义 | 方向 |
| --- | --- | --- |
| **I1 主题残留** | 话题切换后回答与**旧话题**的相似度（词重叠 + 主题分类器概率） | 越低越好 |
| **I2 前提继承** | 旧话题的**错误前提**（如"地球是方的"式自造前提）出现在新话题回答中的比例 | 越低越好 |
| **I3 反复纠结** | 回答中"复述上文"的句子占比（由固定判据/分类器判定） | 越低越好 |
| **任务成功率** | 新话题任务本身是否完成（防止"为了不纠结而不干活"） | 越高越好 |

> ⚠️ 需要**上下文预算对齐**：B 臂与 C 臂的信息量相同，且 B 臂的上下文被塞满到与 C 臂"等效"
> —— 否则会被质疑"B 臂本来就吃亏"。对齐方式在 T3 里设计并记录。

### 3.4 成本（RQ4）

写入延迟 ms/条（分位数）、读取延迟 ms、峰值显存 MB、上下文 token 节省量、磁盘占用 KB/条。

## 4. 基线臂（全部必跑）

| 代号 | 说明 | 作用 |
| --- | --- | --- |
| `Frozen` | 冻结模型，无记忆 | 下界 / 幻觉率 |
| `PromptOnly` | 提示词模板在，但无写入 | 剥离格式效应（P5） |
| `Context-Oracle` | 记忆内容**放进上下文** | 上界参照（也是 RQ3 的 B 臂） |
| `RAG` | 外挂向量库，检索后注入 | 最强工程 baseline |
| `Dense-LoRA` | 单个稠密 LoRA 持续微调（无槽位） | 证明槽位划分的价值 |
| `Full-Write` | 每条都写（无写入判据） | 写入策略的上界 |

## 5. 受控合成基准（T1 起实现）

**结构**（每个 episode）：
```
[写入段]  w_1 ... w_N   ← 每条承载一个记忆项（事实/偏好/经验/噪声）
[驱逐]    清空写入段（P1 断言）
[探针段]  q_1 ... q_M   ← 查询，上下文不含答案（P1/P2 断言）
[对照段]  n_1 ... n_L   ← P3 负对照（未写实体）
```
**实体**：全部虚构自造词（如 `Velmora / Trennick`），值随机生成 ⇒ 消灭预训练知识污染（见 `00` §6.1）。

**子集**：
- `facts`（事实）、`prefs`（偏好）、`lessons`（经验/流程性）、`noise`（噪声，测淘汰）；
- `inertia`（惯性子集）：旧话题给**错误前提** → 切新话题 → 测 I1–I3；
- `capacity`（容量子集）：连续写 $N > K$ 条，测淘汰。

**规模**：T1 先 200 episode（每 episode 5 写 5 问），跑得动再扩；随机种子全程固定并入库到实验配置。

## 6. 统计与报告

- 所有主指标报告 **均值 + 95% bootstrap CI**（≥1000 次重采样），**不许只给一个点估计**；
- 每个实验**至少 3 个种子**（数据种子 + 训练种子），报告种子间方差；
- 单测覆盖率不作为成果，但**协议断言必须有单测**（P1/P2/P4 各至少 1 条）；
- 任何"提升"都必须给出绝对数值与样本量，不写"显著提升"这类空话。
